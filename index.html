About

I like it when an interface explains itself.

I'm a motion and UI/UX designer in Hyderabad. I design interface screens in Figma and animate them in After Effects: splash screens, loaders, pairing and loading states, navigation displays and brand motion.

To me, motion is part of how an interface communicates. It shows what the system is doing, directs attention and makes transitions easy to follow, in the product's own visual language. I also use AI tools to explore ideas faster and refine results.

Craft

What motion does in an interface.

Show state

The Nuclyo pairing pulse moves through discovery, handshake and connection, so a user can read the state without a line of text.

Direct attention

The RYDYT compass pulse points to the next waypoint, so a rider stays oriented in a single glance.

Explain transitions

The Nuclyo splash flows straight into biometric sign-in, so the launch and the next step feel like one movement.
